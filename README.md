# SessionGuard

Модуль для Heroku / Hikka: показывает все активные сессии Telegram-аккаунта —
устройство, платформу, приложение, IP и локацию, время входа и последней активности.
Умеет завершать чужие сессии.

## Установка

```
.dlm https://raw.githubusercontent.com/qrrrv/SessionGuard/main/SessionGuard.py
```

## Команды

| Команда | Что делает |
|---|---|
| `.devices` | список активных сессий |
| `.devices kill 2` | завершить сессию №2 |
| `.devices kill all` | завершить все чужие сессии |
